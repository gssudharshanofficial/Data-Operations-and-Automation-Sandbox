# 📊 Data Operations, Systems Architecture & Automation Sandbox

Welcome to my centralized engineering ecosystem. This repository serves as a functional showcase of my self-taught capabilities in backend automation pipelines, relational database architecture, and responsive user interfaces. 

Rather than maintaining fragmented scripts, this workspace consolidates production-grade operational utilities built to optimize enterprise data workflows.

---

## 📁 Ecosystem Architecture & Directory Map

### 1. 🗄️ [SQL Systems Layout](./sql-systems/)
* **Core Asset:** `corporate_inventory_schema.sql`
* **Capabilities:** Relational database schema execution, precise data constraint mapping, and aggregate performance analytical metrics (`GROUP BY`, aggregate functions).
* **Target Focus:** Minimizing data entry anomaly rates through automated constraints and audit tracking structures.

### 2. 🐍 [Python Automation Pipelines](./python-automation/)
* **Core Asset 1:** `it_support_automation.py`
* **Capabilities:** Automated string parsing of server log logs, conditional alert routing logic, and diagnostic support output metrics.
* **Core Asset 2:** `log_pipeline_engine.py`
* **Capabilities:** Standalone Extract-Transform-Load (ETL) utility built to automatically convert unstructured string logs into structured SQL relational database insertion scripts.
* **Target Focus:** Defusing critical server system bottlenecks by replacing manual monitoring tasks with optimized backend automation scripts.

### 3. 🌐 [Frontend UI Interfaces](./frontend-ui/)
* **Core Assets:** `index.html`, `style.css`
* **Capabilities:** Structural semantic HTML5 formatting and clean user interface layout configurations managed via pure custom CSS3.

## 🚀 Execution & Verification Guide

### Running the IT Security Log Auditor
```bash
python python-automation/it_support_automation.py
```

### Running the ETL Log Pipeline Engine
```bash
python python-automation/log_pipeline_engine.py
```

### Running the SQL Compliance Reports
Execute the code blocks inside `corporate_inventory_schema.sql` within standard MySQL or PostgreSQL database compilers to initiate the multi-table database configuration, inject mock datasets, and run analytical reporting queries automatically.
